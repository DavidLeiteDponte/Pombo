# 🐦 Pombo

> Transforma el caos mental en rutinas estructuradas en cuestión de segundos.

**Pombo** es un asistente de productividad y organización personal diseñado para estudiantes y jóvenes profesionales. Ayuda a superar la parálisis por análisis y la desorganización estructurando tareas, hábitos y objetivos mediante IA con cero fricción de configuración.

### ✨ Características Principales
- 🧠 **Captura directa del caos:** Procesa notas rápidas de texto o voz y las transforma en planes de acción estructurados.
- ⏱️ **Bloques de enfoque y micro-rutinas:** Desglosa pendientes en tareas realizables para acelerar victorias tempranas.
- 📅 **Gestión integral:** Módulos integrados para proyectos, tareas, hábitos y métricas diarias.
